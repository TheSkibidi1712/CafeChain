# Nhãn Phân Loại (Triage Labels)

Các skill sử dụng 5 vai trò phân loại chuẩn. File này ánh xạ các vai trò đó sang chuỗi nhãn thực tế được dùng trong trình theo dõi issue của repo.

| Nhãn trong mattpocock/skills | Nhãn trong tracker của ta | Ý nghĩa                                           |
| ---------------------------- | ------------------------- | -------------------------------------------------- |
| `needs-triage`               | `needs-triage`            | Người quản lý cần đánh giá issue này               |
| `needs-info`                 | `needs-info`              | Đang chờ người báo cáo cung cấp thêm thông tin    |
| `ready-for-agent`            | `ready-for-agent`         | Đã đầy đủ thông tin, agent có thể tự xử lý        |
| `ready-for-human`            | `ready-for-human`         | Cần con người triển khai                            |
| `wontfix`                    | `wontfix`                 | Sẽ không được xử lý                                |

Khi một skill đề cập đến vai trò (ví dụ: "áp dụng nhãn triage AFK-ready"), hãy dùng chuỗi nhãn tương ứng từ bảng trên.

Chỉnh sửa cột bên phải để khớp với bộ nhãn bạn thực sự sử dụng.

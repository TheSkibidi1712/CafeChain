## Kỹ năng của Agent

### Trình theo dõi issue

Các issue được theo dõi trên GitHub Issues tại TheSkibidi1712/CafeChain. Xem `docs/agents/issue-tracker.md`.

### Nhãn phân loại (Triage labels)

Sử dụng bộ nhãn mặc định (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). Xem `docs/agents/triage-labels.md`.

### Tài liệu domain

Bố cục đơn ngữ cảnh (một CONTEXT.md + docs/adr/ tại thư mục gốc). Xem `docs/agents/domain.md`.
